# 🎨 Palettor - Extrator Inteligente de Paletas

Uma aplicação web moderna e elegante para extrair paletas de cores perfeitas de suas imagens.

## ✨ Características Principais

- **🎯 Extração Inteligente**: 3 algoritmos diferentes para diferentes necessidades
- **🏷️ Nomes Reais de Cores**: Identificação precisa com nomes de cores CSS/web
- **♿ Teste de Contraste WCAG**: Ferramenta profissional de acessibilidade
- **🌈 Gerador de Gradientes**: Visualize combinações automaticamente
- **📋 Exportação Fácil**: Copie paletas para seus projetos
- **🎨 Interface Moderna**: Design vibrante com animações suaves
- **📱 Totalmente Responsivo**: Funciona perfeitamente em todos os dispositivos

## 🚀 Como Usar

1. **📁 Carregue** uma imagem por drag & drop ou clique no botão
2. **🎯 Escolha** o método de extração (Predominante, Vibrante, Balanceada)
3. **🎨 Explore** a paleta gerada com nomes reais de cores
4. **♿ Teste** contraste entre cores para acessibilidade
5. **📋 Exporte** para seus projetos

## 🎯 Métodos de Extração

- **🎯 Predominantes**: Cores mais frequentes na imagem
- **⚡ Vibrantes**: Cores com alta saturação e impacto visual  
- **⚖️ Balanceadas**: Variedade equilibrada de matizes

## ♿ Teste de Contraste WCAG

O Palettor inclui ferramentas profissionais de acessibilidade:

### Níveis WCAG:
- **✅ AAA (7:1+)**: Excelente - Perfeito para textos pequenos
- **✅ AA (4.5:1+)**: Bom - Adequado para textos normais  
- **❌ Falha (<4.5:1)**: Ruim - Não recomendado para textos
